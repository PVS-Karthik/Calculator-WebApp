# Calculator Web Application

## 🚀 Project Overview

A responsive and interactive Calculator Web Application developed using HTML, CSS, and JavaScript designed to perform basic arithmetic operations with a clean and modern user interface. The application supports real-time calculations, keyboard input handling, error management, and smooth button interactions for an enhanced user experience.

---

## ✨ Features

* Basic Arithmetic Operations
* Addition, Subtraction, Multiplication, Division
* Interactive Button Controls
* Keyboard Input Support
* Real-Time Calculations
* Error Handling
* Responsive User Interface
* Smooth Hover Animations
* Clean Modern Design
* Lightweight Performance

## 🛠 Technologies Used

* HTML5

* JavaScript
